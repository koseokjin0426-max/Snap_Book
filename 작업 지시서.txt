스냅 사진 작가를 위한 예약 웹페이지를 만들어줘.
현재 이 작가는 카카오톡 오픈 채팅으로 예약을 받고 있는데,
웹페이지를 만들어서 링크 하나로 공유하려고 해.

### 목적
- 고객이 링크 접속 → 폼 작성 → 제출만으로 예약이 끝나는 원페이지 웹앱
- 작가는 제출된 예약 건을 한눈에 확인하고, 엑셀(CSV)로 내려받을 수 있어야 함

### 예약 폼 입력 항목 (핵심: 최대한 "타이핑"이 아닌 "선택"으로)
1. 성함 (필수, 텍스트 — 이건 어쩔 수 없이 입력)
2. 전화번호 (필수, 숫자 키패드 + 하이픈 자동 포맷) + 예약 확인 위한 e-mail 주소
3. 촬영 스타일 (필수, 버튼/칩 형태로 선택: 스냅 / 프로필 / 가족사진 / 커플 / 기타)
   - "기타" 선택 시에만 텍스트 입력란 노출
4. 희망 촬영 날짜 (필수, 달력에서 날짜 선택 — 지난 날짜는 비활성화)
5. 희망 촬영 시간 (필수, 미리 정의된 시간대 슬롯을 버튼으로 선택. 예: 오전 9시 / 10시 / ... 저녁 6시. 직접 입력 X)
6. 촬영 장소 (필수, 자주 쓰는 지역을 칩으로 먼저 제시 + "직접 입력" 옵션. 예: 성수 / 연남 / 한강 / 스튜디오 / 직접 입력)
7. 요청사항 / QnA (선택, 여러 줄 텍스트 — 여기만 자유 입력)

> 설계 원칙: 고객이 폼을 채우는 데 드는 "타이핑"을 최소화한다.
> 날짜·시간·스타일·장소는 모두 탭/클릭으로 고르는 UX로 구현할 것.

### 디자인 방향
- 사용자가 보기 편하고 예쁜 스타일 (사진작가의 감성이 느껴지되 과하지 않게)
- 포인트 컬러: **주황색과 파란색** 두 가지를 포인트로 사용
  - 예: 주황을 메인 액션(선택된 상태, 제출 버튼), 파랑을 보조/링크/포커스에 배치하거나
    네가 조화롭게 역할을 나눠서 세련되게 써줘. 두 색이 싸우지 않고 보완되도록 톤을 정리할 것.
  - 배경/텍스트는 중립 톤으로 잡아 두 포인트 컬러가 살아나게
- 선택된 항목은 시각적으로 명확히 (칩/버튼 selected 상태 디자인 신경써줘)
- 모바일에서 고객이 폼을 작성하는 상황이 압도적으로 많음 → **모바일 우선 반응형**
- 접근성 기본기 준수: 라벨-인풋 연결, 키보드 포커스 링, 색 대비, 터치 타깃 충분히 크게

### 기능 요구사항
- 제출 시 필수 항목 검증, 미입력 항목은 인라인 에러로 안내
- 제출 완료 후 확인 화면: "예약이 접수되었습니다" + 접수 내용 요약 표시
- 관리자 화면에서 예약 목록을 테이블로 확인
  - 컬럼: 접수일시, 성함, 전화번호, 촬영 스타일, 희망 날짜/시간, 장소, 요청사항
  - 최신순 정렬
- 관리자 화면에서 "엑셀로 내보내기" 버튼 → CSV 다운로드 (한글 안 깨지게 UTF-8 BOM 처리)
- 예약 데이터는 새로고침/재접속해도 유지되어야 함 (아래 배포 스택에 맞는 영속 저장 사용)
- 관리자 화면은 간단한 접근 보호를 둘 것 (예: 관리자용 비밀 URL 경로 또는 간단한 비밀번호 게이트 — 무겁지 않게)
